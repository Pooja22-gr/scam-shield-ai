# 🛡️ ScamShield AI

> **Explainable Threat Scoring Engine & Anti-Fraud Defense System**

ScamShield AI is an interactive, real-time cybersecurity web platform built to detect and analyze employment and rental scams targeting vulnerable applicants. Featuring a unique bioluminescent ocean-cyberpunk interface, ScamShield combines AI-driven prompt evaluation, OCR document processing, and an offline-first heuristic rules engine to deliver transparent, actionable fraud detection.

---

## ✨ Key Features

- 🎯 **Dynamic Threat Scoring Index (0–100%):** Replaces static labels with a dynamic, additive weight-based risk matrix detailing specific point contributions.
- 🪝 **Interactive "Hook Vector" Attack Graph:** Renders a step-by-step visual flowchart showing how the detected scam progresses (e.g., *Initial Offer → Pressure Deadline → Fake Check → Off-Platform Shift*).
- 🔍 **Entity & Domain Cross-Checker:** Automatically extracts company names, email domains, phone numbers, and communication channels to flag suspicious lookalike domains or free webmail usage.
- 📑 **Multimodal Document & OCR Inspection:** Processes raw text, direct document uploads, and images (via Base64/OCR) to catch hidden fraud patterns in offer letters and leases.
- 🌐 **Real-Time Multilingual Support:** Instant translation support for UI controls and scan reports (Hindi, Spanish, French, German, English) to protect non-native speakers.
- 🛡️ **Offline Heuristic Engine:** Built-in client-side fallback scanner that ensures zero downtime and complete functionality even during API network rate limits or 503 high-demand spikes.
- 📄 **1-Click Forensic Report & Safe Response Generator:** Generates downloadable, printable evidence summaries for authorities (FTC/IC3) and creates polite, personal-data-safe reply templates to probe unverified senders.
